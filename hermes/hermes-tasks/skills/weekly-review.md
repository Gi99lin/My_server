# Skill: Weekly Review — воскресный черновик недельного пульса

Запускается cron'ом в воскресенье 11:00 (после утреннего кофе-ритуала,
не вместо него).

## Сбор
```bash
yt.py list --query "State: Done resolved date: {This week}"
yt.py list --query "#Unresolved State: {In Progress}"                 # застрявшее
yt.py list --query "#Unresolved State: Next"
yt.py list --query "#Unresolved tag: needle-mover"
```

## Формат сообщения (черновик для его Weekly-заметки в Obsidian)

```
🧭 Неделя NN — черновик пульса

✅ Сделано (X): <по строке на задачу, сгруппировано по сферам>

🧊 Застряло: <In Progress старше 7 дней — по строке + вопрос
   «разбить мельче / в Waiting / дропнуть?»>

По направлениям Компаса:
- 🏗 Проекты: <что сдвинулось по бот-тесту/фрилансу, 1 предложение>
- 💰 Финансы: <перевод в день зарплаты был? — только если была зарплата>
- 🧠 Здоровье: <N активных сессий, шаг чекапа>
- ❤️ Отношения: <ритуал состоялся? активность вне дома?>
- 💼 Карьера: <только если что-то было>

🔮 Кандидаты на needle-mover следующей недели:
1. <...>  2. <...>  3. <...>
Какую берём? (одну)
```

## После ответа Ивана
1. Снять tag needle-mover со старой задачи, повесить на выбранную:
   `yt.py cmd <ID> "tag needle-mover"`
2. Решения по застрявшим применить (декомпозиция → intake-процедура).
3. Напомнить одной строкой: «Черновик выше можно вставить в
   Жизнь/Weekly/2026-WNN — я в vault не пишу, это твоя территория.»

## Правила
- Сферы, где ничего не было, — одна строка «—», не выдумывай прогресс.
- Кандидатов на needle-mover бери из Next проекта PROJ в первую очередь
  (Компас: Проекты — единственный двигатель).
- Это черновик и вопросы. Решения принимает Иван.
