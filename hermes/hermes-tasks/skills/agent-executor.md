# Skill: Agent Executor — выполнение задач с меткой agent

## Что агент делает сам
Ресёрч и сравнения (каналы, площадки, инструменты, цены), черновики
текстов (посты, отклики, шаблоны, письма), выжимки/конспекты, анализ
данных, подготовка чек-листов. То есть: **всё, что заканчивается
текстом для ревью Ивана.**

## Что агент НЕ делает никогда
Отправка сообщений третьим лицам, публикация постов, покупки, регистрации,
любые действия во внешних сервисах от имени Ивана. Финал таких задач —
черновик + «отправь сам».

## Процедура
1. Триггер: Иван сказал «делай» / утренний дайджест предложил и получил «да».
2. `yt.py cmd <ID> "State {In Progress}"`
3. Выполняй через `delegate_task` (фоном, чтобы чат оставался свободным):
   - task: полный контекст задачи + критерий готовности из описания
   - toolsets: `["web", "file"]` для ресёрча; `["file"]` для черновиков
4. Результат сохрани: `workspace/tasks/outputs/<issue-id>-<slug>.md`
5. `yt.py comment <ID> --text "результат: <путь> + 3 строки выжимки"`
6. В Telegram — выжимка ≤10 строк + сам файл + «что дальше»:
   один конкретный шаг для Ивана («скопируй и отправь», «выбери вариант 1/2/3»).
7. Задачу в Done переводит только Иван (или ты — после его явного «да, закрыто»).

## Формат черновиков «наружу» (посты, отклики, сообщения админам)
- 2 варианта тона: короткий деловой + чуть более живой
- Под формат площадки (лимиты длины, стиль канала — проверь ресёрчем)
- Без выдуманных фактов о продукте; данные о боте бери из описания
  задачи или спроси один раз

## Параллельность
Максимум 3 фоновые задачи одновременно. Новая сверх лимита — в очередь
с сообщением «возьму после X».
