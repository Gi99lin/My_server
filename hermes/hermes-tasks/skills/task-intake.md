# Skill: Task Intake — из сырой мысли в оформленную задачу

## Вход
Любое сообщение Ивана, содержащее задачу, идею, «надо бы», жалобу на
несделанное, пересланный пост. Голосовые — та же процедура.

## Шаг 1. Классификация (молча, сам)
- **Проект:** упоминание работы/НТ/коллег → WORK; бот/фриланс/сервер/
  генератор ТК → PROJ; здоровье/дом/Саша/документы → LIFE.
- **Sphere, Size, Energy** — по конвенциям из `youtrack-ops`.
- **Дубликат?** `yt.py list --query "#Unresolved summary: *ключевое слово*"`.

## Шаг 2. Один вопрос (или ноль)
Задай вопрос ТОЛЬКО если без него план развалится. Типовые допустимые:
- «Есть жёсткий срок или как получится?»
- «Что будет результатом — X или Y?»
Всё остальное — допущение, показанное в предложении: *(допускаю: без срока)*.

## Шаг 3. Ленивая декомпозиция
Признаки, что декомпозиция НУЖНА: Size L/XL; глаголы-исходы
(«разобраться», «начать», «организовать», «подготовиться»); задача уже
всплывала и не сделалась; Иван сам говорит «не знаю, с чего начать».

Правила разбиения:
- 3-6 подзадач, каждая = физическое действие ≤2 ч.
- Первая подзадача — выполнимая сегодня за ≤30 мин (сломать порог входа).
- Последняя — критерий готовности («…и тогда задача закрыта»).
- Подзадачи, которые можешь сделать сам, помечай 🤖 → tag agent.

## Шаг 4. Предложение (один месседж)
```
📥 PROJ · 🏗 Проекты · M · Light · без срока (допускаю)
«Завести профиль на Kwork»
1. Открыть Kwork, пройти регистрацию — 15 мин
2. 🤖 Черновик позиционирования + 3 кейса из портфолио
3. Заполнить профиль из черновика — 30 мин
4. Готово = профиль виден в поиске
Создаю?
```

## Шаг 5. Создание
После подтверждения: создай родителя и подзадачи (`--parent`), верни ID.
Тривиальный случай (S, без срока, без декомпозиции) — создавай сразу без
вопроса, ответом «✍️ LIFE-23 создал: …».

## Шаг 6. Хвост
Если есть 🤖-подзадачи — предложи: «Пункт 2 могу сделать сейчас, фоном. Делать?»

## Анти-паттерны
- ❌ «Уточни, пожалуйста, что ты имеешь в виду» без конкретного вопроса
- ❌ Декомпозиция задачи «Позвонить в клинику» на 4 шага
- ❌ Дедлайн «через неделю», потому что «так принято»
- ❌ Простыня из 15 подзадач
