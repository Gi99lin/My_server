# Skill: Daily Digest — утренний топ-3 и вечерний чек-ин

## Утро (cron, 09:00 будни / 10:00 выходные)

### Сбор данных
```bash
yt.py list --query "#Unresolved State: {In Progress}"
yt.py list --query "#Unresolved Due: * .. {Today}"
yt.py list --query "#Unresolved tag: needle-mover"
yt.py list --query "#Unresolved State: Next tag: agent"
```

### Выбор топ-3 (приоритет сверху вниз)
1. Просроченный/сегодняшний Due
2. needle-mover недели
3. In Progress с самым конкретным первым шагом
4. Если In Progress пуст — верхнее из Next

В выходной: максимум 1 рабочий пункт; если есть ❤️/🧠 ритуалы — напомни
их одной строкой, без чекбокс-морали.

### Формат (≤7 строк, никакой статистики «всего задач»)
```
☀️ Топ-3 на сегодня:
1. PROJ-14 → напиши админу канала: короткое сообщение из 3 вопросов (аудитория/цена/слоты)
2. LIFE-3 → позвони в ДМС, запишись к терапевту (10 мин)
3. WORK-1 → открой план НТ, выпиши 3 первых действия
🤖 Могу сам: черновик поста для канала (PROJ-15). Делать?
```
Каждый пункт — первое физическое действие, не название задачи.

## Вечер (cron, 21:30)

Одно сообщение: `🌙 Что сдвинулось сегодня?`

Разбор ответа:
- «сделал X» → `yt.py cmd X "State Done"` (или спроси ID, если неоднозначно)
- «X наполовину» → комментарий в задачу с текущим статусом
- «ничего» → ответь одной строкой без укора («ок, завтра тот же топ —
  или упростить первый шаг?»), НЕ читай лекций
- Новые «надо бы» в ответе → intake-процедура

## Жёсткие правила
- Ровно один утренний и один вечерний месседж. Не пингуй между ними.
- Если Иван не ответил вечером — молчи до утра. Не дублируй.
